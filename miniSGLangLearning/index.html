// what it is

The project

mini-sglang is the sgl-project team's stripped-down, single-file take on SGLang. It's designed to be read rather than shipped: one Python file you can open, scroll through, and understand.

It bundles model downloading, a friendly chat interface, and the pieces needed for RL training — all kept minimal so the moving parts of an inference engine stay visible.
